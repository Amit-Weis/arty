About Arty
Arty is a companion robot project designed to bring intelligent interaction and personality into everyday life. Built with care and innovation, Arty represents the next step in personal robotics, combining responsive behavior modes with an intuitive control interface. This project is a labor of love, exploring the boundaries of what companion robots can be.
